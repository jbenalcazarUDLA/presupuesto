PLANIFICADOR DE PRESUPUESTO - SPRINT 1 (SIN PYTHON)

1. Descomprima la carpeta.
2. Ejecute start.bat.
3. Se abrirá index.html en el navegador.

No requiere Python, Flask, Node.js ni instalación adicional.

Las cuentas iniciales se cargan automáticamente y los cambios se guardan en el almacenamiento local del navegador.

IMPORTANTE: la persistencia depende del navegador y del perfil de Windows donde se ejecute. No borre los datos del sitio del navegador si desea conservar la información.

Esta versión es intencionalmente local y corresponde al Sprint 1.
